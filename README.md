
# Git Practice Starter (VS Code)

This small Node.js project is designed for hands-on Git practice.
Use it together with the step-by-step labs I shared in chat.

## Project structure
```
git-practice/
├─ .gitignore
├─ README.md
├─ package.json
├─ src/
│  ├─ index.js
│  └─ utils.js
└─ data/
   └─ users.json
```

No external dependencies are required; you can run it with `node src/index.js`.

## Quick start
1. Open this folder in VS Code.
2. Open the Terminal (Ctrl+`) and run:
   ```bash
   git init
   git add .
   git commit -m "chore: initial commit"
   ```
3. Start the labs from **Lab 1** in the chat instructions.
4. practicing staging
